# 08 — 書類生成エージェント

契約更新書類と管理台帳を、既存資料から自動生成します。

| ファイル | 内容 |
|---|---|
| [`renewal_doc_agent.py`](renewal_doc_agent.py) | 更新書類作成エージェント |
| [`ledger_processor.py`](ledger_processor.py) | 台帳作成の処理エンジン |

## extract / compute / write を分ける

`renewal_doc_agent.py` は、初版（1本の長い処理）から次の形に作り直しました。

```
extract   資料から値を取り出す      … LLM、ページ出典を付ける
compute   取り出した値から計算する   … コードのみ
write     書類の様式に流し込む      … コードのみ
```

分けた理由は2つです。

1. **計算をLLMから外す。** 抽出と計算が同じ呼び出しに混ざっていると、
   読み間違いなのか計算間違いなのかが切り分けられません
2. **出典を残せる。** 抽出した各項目に「どのPDFの何ページから取ったか」を付けています

## 人が確認する前提で作る

処理の最後に、**PDFページの画像を埋め込んだレビュー用HTML**を自動生成します。
抽出した値の隣に元のページ画像が並ぶので、確認する人が原本を開き直さずに済みます。

書類生成は、間違ったまま出ると後段の影響が大きい種類の仕事です。
全自動にするより、確認の手間を下げるほうに寄せました。

## ログ

`print` をやめて構造化ログ（JSON）にしています。
サンドボックスは標準出力しか返さないため、
実行後に何が起きたかを機械的に追えるようにしておく必要がありました。
