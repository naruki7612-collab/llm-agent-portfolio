# 04 — 固定資産税 転記アシスタント

納税通知書（課税明細書）のPDFから物件ごとの
**評価額 / 固定資産税課税標準額 / 都市計画税課税標準額** を読み取り、
管理台帳Excelの自治体シートの該当行へ転記します。

- [`property_tax_transcriber.py`](property_tax_transcriber.py) — 転記エンジン
- [`docs/requirements.md`](docs/requirements.md) — 依頼要件

## 設計方針

**fail closed。** 全件が検証を通ったときだけ書き込みます。1件でも落ちたら1セルも書きません。
一部だけ書き込まれた台帳は、何が正しくて何が間違っているか分からない状態になり、
人の確認コストがかえって増えるためです。

**数値の計算は必ずコードで行う。** LLMに任せるのは「画像から数字を読む」ことだけです。

**触る範囲を限定する。** 見出し・数式・書式・対象外の行とシートには一切書き込みません。

## 3段階に分かれている

```
render_pdf(pdf, workdir)        PDF → 画像（/Rotate を適用して正立させる）
  ↓
dry_run(records, covers, ...)   検証のみ。ファイルには触れない
  ↓
commit(plan, xlsx, out_path)    全部通ったときだけ書く
```

`dry_run` を独立させているのは、書き込む前に「何がどこに入るか」を人が確認できるようにするためです。

## 環境依存の扱い

PDFのラスタライズに使うライブラリが入っていない環境があるため、
検出できなければ専用の例外を投げて、必要な拡張を読み込んでから再実行する形にしています。
「入っている前提で書いて実行時に落ちる」よりも、何を足せばいいかが分かるようにしました。
